## MODIFIED Requirements

### Requirement: Неудачный вход при старте — отказ сразу
Пока старт ждёт подключения и обработки, он MUST проверять процесс. Окно входа «Доступ к информационной базе» или окно ошибки `V8NewLocalFrameBaseWnd` поверх заставки без главного окна — MUST сразу `login_failed` с `dialog`, процесс и окно MUST закрыться до ответа; `error` MUST называть профиль, логин и причины. Процесс вышел — MUST сразу `client_exited` с кодом выхода. Иначе MUST ждать до `wait`. Окна — Windows, обычный рабочий стол.

#### Scenario: Пользователя нет в базе
- **WHEN** `client start --profile "роль:rmzds_admin"`, логина нет в базе, 1С открыла окно «Доступ к информационной базе»
- **THEN** через секунды после появления окна код выхода ненулевой, в stderr JSON с `code: "login_failed"`, `dialog: "Доступ к информационной базе"`, `client_stopped: true`; процесса 1С нет

#### Scenario: Неверный пароль
- **WHEN** логин есть, пароль профиля неверный, 1С открыла окно входа
- **THEN** отказ `login_failed`, как без пользователя; `error` называет профиль, логин и причины: нет пользователя, пароль неверный или не передан, нет права входа

#### Scenario: Нет прав на запуск клиента
- **WHEN** пользователь есть, права на запуск клиента нет: после заставки «Загрузка конфигурационной информации...» у процесса окно `V8NewLocalFrameBaseWnd` «1С:Предприятие» с владельцем, главного окна нет
- **THEN** через секунды после появления окна отказ `login_failed` с `dialog: "1С:Предприятие"`; `error` называет профиль, логин и «Нет прав на запуск требуемого вида клиента» как пример текста 1С; процесса 1С и окна нет

#### Scenario: Процесс вышел во время подготовки
- **WHEN** процесс 1С завершился после подключения, пока обработка не готова
- **THEN** отказ `client_exited` с кодом выхода в `error`, без ожидания `wait`

#### Scenario: Долгий обычный старт
- **WHEN** 1С 90 с показывает «Загрузка конфигурационной информации...», затем главное окно и окна уведомлений, `wait` 600
- **THEN** запуск ждёт и завершается `ok: true, execution_ready: true`

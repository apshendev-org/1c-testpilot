## ADDED Requirements

### Requirement: Уже открытое окно обновляется
Если `execute_command` вернул окно, которое было открыто до команды, и в этом окне есть кнопка `ФормаОбновить`, движок MUST нажать её без ожидания эффекта и вернуть `refreshed: true`. Новое окно, окно без этой кнопки и неудачное нажатие MUST давать ответ без `refreshed` и без ошибки, как раньше.

#### Scenario: Список открыт до создания данных
- **WHEN** список открыт, затем создан документ, затем `execute_command` того же списка
- **THEN** нажата `ФормаОбновить`, ответ `ok: true`, `refreshed: true`, `goto_row` находит новый документ

#### Scenario: Список открывается впервые
- **WHEN** `execute_command` открыл новое окно
- **THEN** ничего не нажимается, `refreshed` в ответе нет

#### Scenario: Открытое окно без кнопки обновления
- **WHEN** `execute_command` вернул уже открытое окно без `ФормаОбновить`
- **THEN** ответ `ok: true` без `refreshed` и без ошибки

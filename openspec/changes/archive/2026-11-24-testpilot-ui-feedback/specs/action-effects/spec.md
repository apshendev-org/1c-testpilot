## MODIFIED Requirements

### Requirement: Ожидание и повтор до таймаута
Если эффекта нет и нет ошибок 1С, движок MUST ждать эффект до `timeout` и MUST NOT повторять действие: «ничего не изменилось» не доказывает потерю нажатия, а повтор выполнил бы команду второй раз. При сообщении об ошибке или окне ошибки MUST вернуть `ok: false` сразу, без ожидания.

#### Scenario: Медленная запись
- **WHEN** запись документа завершается через 3 с при `timeout` 30 с
- **THEN** ответ `ok: true` без повторного клика

#### Scenario: Окно ошибки
- **WHEN** после клика открывается окно ошибки 1С
- **THEN** ответ `ok: false` сразу, с текстом окна

#### Scenario: Значения полей не читаются
- **WHEN** состояние формы недоступно, команда меняет только значение поля, эффект не виден до `timeout`
- **THEN** `effect_not_observed`, команда нажата один раз

#### Scenario: Эффект не виден
- **WHEN** форма читается, команда меняет только текущую область табличного документа, эффект не виден до `timeout`
- **THEN** `effect_not_observed`, команда нажата один раз

### Requirement: Исключение без видимого эффекта
`click` MUST принимать `expect="none"` для кнопок без наблюдаемого эффекта. С ним `ok: true` означает, что команда принята, а ожидания нет. Клик по группе формы MUST идти так же без явного `expect`: у переключения группы нет наблюдаемого состояния.

#### Scenario: Кнопка без эффекта
- **WHEN** агент нажимает кнопку с `expect="none"`
- **THEN** ответ `ok: true` сразу после принятия команды

#### Scenario: Сворачиваемая группа
- **WHEN** агент нажимает сворачиваемую группу формы без `expect`
- **THEN** ответ `ok: true` сразу после принятия команды, группа нажата один раз

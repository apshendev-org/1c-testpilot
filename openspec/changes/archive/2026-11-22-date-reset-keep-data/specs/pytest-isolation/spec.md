## MODIFIED Requirements

### Requirement: Сброс клиента к начальной странице
Система MUST предоставлять `Client.reset()`. Он закрывает все окна до начальной страницы, отменяет незавершённое редактирование строк, закрывает открытый список подбора текущего поля с отменой его редактирования и отвечает «Нет» на вопрос о сохранении. Если окна не закрылись, MUST вызвать ошибку с описанием оставшегося окна.

#### Scenario: Открыт модифицированный документ
- **WHEN** открыт документ с несохранёнными изменениями и редактируемой строкой
- **THEN** после `reset()` активна начальная страница, документ не записан

#### Scenario: Открыт список подбора
- **WHEN** в форме документа после ввода текста открыт список подбора поля
- **THEN** после `reset()` активна начальная страница, без `reset_failed`

#### Scenario: Окно не закрывается
- **WHEN** окно отказывается закрываться
- **THEN** `reset()` вызывает ошибку с ключом и заголовком окна

## ADDED Requirements

### Requirement: Данные теста можно оставить
С опцией pytest `--tc-keep-data` фикстура `testpilot_data` MUST NOT удалять учтённые объекты после теста. Без опции MUST удалять, как раньше.

#### Scenario: Отладка многошагового теста
- **WHEN** тест запущен с `--tc-keep-data`
- **THEN** после теста созданные им объекты остаются в базе и доступны через MCP

## MODIFIED Requirements

### Requirement: input_text сравнивает значение по типу поля
После ввода движок MUST сравнить значение поля с введённым текстом по типу значения: число — численно в формате поля, дата — разобранной датой, булево — значением, строка — точным равенством. Если тип не прочитан, MUST сравнить строки, а при различии — принять ввод, когда текст и представление разбираются как одна дата формата сеанса. Сравнение по началу строки MUST NOT применяться.

#### Scenario: Число в формате поля
- **WHEN** в числовое поле введено «2», а поле показывает «2,000»
- **THEN** ответ `ok: true`

#### Scenario: Другое число
- **WHEN** в числовое поле введено «2», а поле показывает «20»
- **THEN** ответ `ok: false`, `code: value_mismatch`

#### Scenario: Строка с суффиксом
- **WHEN** в строковое поле введено «Протон», а поле показывает «Протон-2»
- **THEN** ответ `ok: false`, `code: value_mismatch`

#### Scenario: Тип поля неизвестен
- **WHEN** обработка Testpilot не подключена и тип значения не прочитан
- **THEN** сравнение — точное равенство строк

#### Scenario: Дата в поле компоновщика настроек
- **WHEN** в поле периода отчёта, тип которого не прочитан, введено «01.01.2026», а поле показывает «01.01.2026 0:00:00»
- **THEN** ответ `ok: true`, `verification: date_text`

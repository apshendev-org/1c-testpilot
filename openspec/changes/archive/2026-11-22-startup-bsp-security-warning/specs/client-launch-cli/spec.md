## MODIFIED Requirements

### Requirement: Запуск клиента по профилю из командной строки
Команда `1c-testpilot client start --profile <имя>` MUST запустить клиент по профилю: `/TESTCLIENT -TPort`, `/Execute` с обработкой, подтверждение предупреждения безопасности, ожидание готовности. Затем MUST отключиться, оставить процесс работать и вывести JSON с `pid`, `host`, `port`, `version`, `execution_ready`. Стартовую форму БСП `ПредупреждениеБезопасности` подготовка MUST закрыть сама кнопкой «ЯОзнакомлен», иначе «НеЗапрещать»; кнопку запрета внешних обработок MUST NOT нажимать.

#### Scenario: Успешный запуск
- **WHEN** выполняется `1c-testpilot client start --profile ws_epf`
- **THEN** код выхода 0, в stdout JSON с `pid` и `port`, процесс 1С продолжает работать после выхода команды, pytest с этим профилем подключается к порту из `.testpilot-clients.json` и исполняет код

#### Scenario: Ролевой профиль
- **WHEN** выполняется `1c-testpilot client start --profile "роль:kfk_user"`, а клиент `роль:kfk_admin` уже работает
- **THEN** клиент kfk_user запущен на следующем свободном порту пула, клиент kfk_admin продолжает работать

#### Scenario: Профиль уже запущен
- **WHEN** `client start` вызывается для профиля, клиент которого работает
- **THEN** новый процесс не запускается, JSON содержит прежние `pid`, `port` и `reused: true`

#### Scenario: Неудачная подготовка
- **WHEN** клиент не стал готов за `wait` профиля или обработка не открылась
- **THEN** запущенный процесс завершён, код выхода ненулевой, в stderr JSON с `code` и `error`

#### Scenario: Предупреждение безопасности БСП при старте
- **WHEN** пользователю профиля при старте открыта форма БСП `ПредупреждениеБезопасности` на странице «После появления права» или «После обновления»
- **THEN** подготовка нажимает «ЯОзнакомлен» или «НеЗапрещать», внешние обработки остаются разрешены, `client start` завершается с `ok: true`

#### Scenario: Форма БСП не принимает ответ
- **WHEN** ни «ЯОзнакомлен», ни «НеЗапрещать» не нажимаются
- **THEN** отказ `helper_startup_blocked` с `dialog: "ПредупреждениеБезопасности"`, процесс завершён

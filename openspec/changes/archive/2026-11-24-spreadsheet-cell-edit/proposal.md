## Why

Поток 1c_bgu20 на макете АРМ (табличный документ со ссылочными ячейками) не смог пройти e2e: после неудачного ввода в ячейку нажатия кнопок формы пропадали, выбрать значение справочника в ячейке через `select_value` нельзя, а `click` без видимого эффекта нажимал повторно. Спайк spike:spk_d8a5084a0c@v1 (`docs/spikes/testpilot-cell-edit` кита) записал это живьём:
- флаг платформы «правка ячейки» после неудачного ввода в ссылочную ячейку отвечает `false`, хотя правка открыта и забирает нажатия; снимает её только `end_edit_current_area(cancel=true)`;
- значение справочника ставится вводом точного представления (`set_area_text` — `verified: true`), а `select_value` и `start_choosing` по полю документа отказывают;
- `click`, не увидев изменения значения поля внешней обработки, повторил нажатие — команда выполнилась дважды.

## What Changes

- Незаконченная правка ячейки — своё состояние testpilot, а не флаг платформы: `begin_edit_current_area` без смены окна оставляет правку незаконченной и при `edit_mode: false`; снимает её `end_edit_current_area`.
- `click` при незаконченной правке ячейки отказывает (`other_input_pending`, подсказка `end_edit_current_area`), а не теряет нажатие.
- `set_area_text`: текст после правки не совпал — правка отменяется (`edit_cancelled`), в ответе подсказка о точном представлении для ссылочной ячейки.
- `select_value` по полю табличного документа ставит `value` в текущую ячейку точным представлением (путь `set_area_text`); `match`, `choice_table`, `choice_column`, `data_type`, `expected` для ячейки — `invalid_argument`.
- **BREAKING** для `click`: повтор нажатия — только когда движок читает значения полей формы (обработка Testpilot отдаёт состояние формы). Без этого повтора нет: `effect_not_observed` с `repeated: false`.
- Не входит: окно Helper после `find_rows` в форме выбора из ячейки (находка bgu20) — любой код Helper при такой форме оставляет Helper активным; отдельное изменение (ветка `bb/bug/testpilot-helper-focus`). Обход — значение ссылочной ячейки точным представлением (`set_area_text`, `select_value`).

## Capabilities

### New Capabilities
- `spreadsheet-edit`: правка ячеек табличного документа — незаконченная правка, отмена при несовпадении, значение ссылочной ячейки.

### Modified Capabilities
- `action-effects`: повтор клика только при полном наблюдении.

## Impact

- `app/_runtime.py` (`_area_edit_started`, `tc_click`, `tc_set_area_text`, `tc_select_value`), `app/_effects.py` (`run`), тесты `tests/` — по записям спайка.

## REMOVED Requirements

### Requirement: Исполнение при активной рабочей форме
**Reason**: Возврат окна командой `ACTIVATE` не работает при форме выбора из ячейки табличного документа, а активизация Helper портит платформе порядок возврата активности.
**Migration**: Требование «Исполнение не меняет активное окно» ниже; вызовы тестов не меняются.

## ADDED Requirements

### Requirement: Исполнение не меняет активное окно
Исполнение кода, запроса, метаданных, функций и чтений формы MUST NOT активировать окно обработки Testpilot. Запрос MUST выполняться через форму запроса обработки, открытую над формой активного окна в режиме «Блокировать окно владельца» и закрываемую её кнопкой «Выполнить». После ответа MUST быть активна та же форма; окно обработки MUST NOT получать активность и после закрытия этой формы.

#### Scenario: Запрос после действий с формой
- **WHEN** тест записал документ в открытой форме и сразу вызывает `execute_query`
- **THEN** запрос выполняется без `reset()`, после ответа активна та же форма документа

#### Scenario: Форма выбора из ячейки табличного документа
- **WHEN** форма выбора открыта из ячейки табличного документа (`begin_edit_current_area`), тест вызывает `find_rows`, затем `choose_row`
- **THEN** после `find_rows` активна форма выбора, после `choose_row` в ячейке выбранное значение, активна форма с табличным документом, а не `no_active_work_window`

#### Scenario: Нет рабочего окна
- **WHEN** активно окно обработки или активного окна нет (старт клиента)
- **THEN** запрос выполняется, форма запроса открывается над обработкой

### Requirement: Незакрытая форма запроса
Если форма запроса осталась открытой (истёк срок, обрыв связи), следующее исполнение MUST сначала разрешить её: прочитать результат прежнего запроса, если он есть, иначе закрыть форму. Оставшаяся форма MUST NOT блокировать рабочее окно после ответа.

#### Scenario: Срок истёк
- **WHEN** `execute_code` истёк по сроку при открытой форме запроса, затем вызван `execute_query`
- **THEN** запрос выполняется, форма запроса закрыта, прежний результат — в `previous_result`, если он пришёл

### Requirement: Форма обработки без текста запросов
Окно обработки Testpilot MUST NOT содержать полей ввода запроса: код и запросы вводятся только в форму запроса и уходят вместе с ней. На форме обработки MUST оставаться только последний ответ и служебные сведения. Обработка без формы запроса MUST давать `helper_version_mismatch`.

#### Scenario: Старая обработка
- **WHEN** клиент запущен с `Testpilot.epf` прежней структуры (поля запроса на форме Helper)
- **THEN** `execute_code` отвечает `ok: false`, `code: helper_version_mismatch`

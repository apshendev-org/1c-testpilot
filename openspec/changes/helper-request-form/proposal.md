## Why

Любой код через обработку Testpilot делает её окно (Helper) активным. Обычно testpilot возвращает прежнее окно командой `ACTIVATE`. Форму выбора, открытую из ячейки табличного документа, так не вернуть: после `find_rows`/`read_rows` testpilot видит `no_active_work_window`, а клавиатура уходит в Helper (находка 1c_bgu20). К тому же платформа запоминает активизацию Helper: когда рабочее окно потом закрывается, фокус уходит в Helper, а не в форму под ним.

Спайк spike:spk_cff9b4db89@v2 (`docs/spikes/testpilot-helper-restore` кита) нашёл решение по образцу VAExtension Vanessa:
- кнопка Helper, нажатая протоколом без `ACTIVATE`, выполняется при активной рабочей форме;
- из неё открывается дочерняя форма с владельцем — этой рабочей формой — в режиме «Блокировать окно владельца»;
- код вводится в дочернюю форму, её «Выполнить» выполняет код и закрывает форму, а платформа сама возвращает активность владельцу.

Helper не становится активным ни разу. После закрытия формы выбора активным становится окно под ней.

## What Changes

- В `Testpilot.epf` появляется форма `Request`: поле запроса и кнопки «Выполнить» для клиента и сервера. Кнопка отдаёт запрос в Helper, получает ответ и закрывает форму.
- Helper: команда `OpenRequest` открывает `Request` с владельцем — формой активного окна, в режиме «Блокировать окно владельца»; если активен сам Helper или окна нет, владелец — Helper. Выполнение запроса — экспортная функция Helper; код по-прежнему выполняется в контексте модуля Helper. Ответ пишется в `ClientResult`/`ServerResult` Helper.
- **BREAKING** для `Testpilot.epf`: с формы Helper уходят поля запроса (`ClientRequest`, `ServerRequest`) и кнопки `RunClient`, `RunServer`. Текст кода на форме Helper не копится, видны только последний ответ и `ServiceInfo`. Обработка прежней структуры — `helper_version_mismatch`.
- testpilot (`execute`: код, запросы, метаданные, функции, чтения формы для `find_rows`/`read_rows` и `click`):
  - нажимает `OpenRequest` без `ACTIVATE`, вводит запрос в `Request` и нажимает «Выполнить», ответ читает из поля Helper;
  - `_focus_service`/`_restore_window` удаляются;
  - форма `Request` — служебная: агентам не видна, рабочим окном не считается.
- Незакрытая форма `Request` (истёк срок, обрыв) следующим исполнением используется для прежнего запроса или закрывается, иначе она держала бы рабочее окно заблокированным.

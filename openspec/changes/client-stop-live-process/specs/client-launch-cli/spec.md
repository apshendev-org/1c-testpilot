## MODIFIED Requirements

### Requirement: Остановка клиента из командной строки
Команда `1c-testpilot client stop` MUST завершить клиент, запущенный `client start`, по `--pid` или по `--profile` (запись в `.testpilot-clients.json`), вместе с дочерними процессами, даже если его порт клиента тестирования уже не слушается. Процесс `--profile` — клиент записи, если это `1cv8*` с `-TPort<порт записи>`. Процесса нет или он чужой — код 0, `"stopped": false`, чужой не трогается.

#### Scenario: Остановка по pid
- **WHEN** выполняется `1c-testpilot client stop --pid <pid из start>`
- **THEN** процесс 1С и его дочерние процессы завершены, код выхода 0

#### Scenario: Процесса нет
- **WHEN** процесс с указанным pid уже завершился
- **THEN** код выхода 0, в stdout `"stopped": false`

#### Scenario: Клиент потерял порт клиента тестирования
- **WHEN** `client stop --profile <профиль>`, процесс записи — `1cv8.exe` с `-TPort<порт записи>`, порт не слушается, процесс держит порт runMcp
- **THEN** процесс завершён, в stdout `"stopped": true`, запись профиля удалена

#### Scenario: PID записи занят другим процессом
- **WHEN** `client stop --profile <профиль>`, PID записи принадлежит процессу без `-TPort<порт записи>` или не `1cv8*`
- **THEN** этот процесс не завершается, код 0, `"stopped": false`, запись удалена

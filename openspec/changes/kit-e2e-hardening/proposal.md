# Proposal

## Why

Кит 1c-agent-kit переходит с Vanessa на этот форк (UI e2e на pytest) и YAxUnit. Спайк `spike:spk_a831396b29@v3` (1С 8.3.27.2342, WS) показал, что сценарий через формы проходит, но агенту, который пишет тесты без человека, мешают:

- запрет `Выполнить` в коде: `Запрос.Выполнить()` недоступен;
- действия, которые отвечают `ok`, хотя эффекта нет;
- ожидание диалогов до таймаута;
- плавающий отказ `select_value`;
- нет сброса клиента, уборки данных и ролевых клиентов.

Принцип изменения: агент делает как можно меньше вызовов и ошибок. Всё, что можно автоматизировать, делает движок, а не агент параметрами.

## What Changes

- **BREAKING** Фильтр идентификаторов кода удалён целиком, включая `Выполнить`/`Execute`/`Вычислить`/`Eval`. `TC1C_CODE_FORBIDDEN_WORDS` и `TC1C_CODE_ALLOWED_WORDS` больше не действуют.
- **BREAKING** `click` и `input_text` возвращают `ok: true` только при подтверждённом эффекте. Движок сам выводит ожидаемый эффект (у стандартных команд — записан, проведён, закрыт, открыта форма; у прочих — любое наблюдаемое изменение), ждёт и один раз повторяет до таймаута. Иначе — ошибка с диагностикой и слепком. `expect="none"` — только для кнопок без видимого эффекта.
- `input_text` сравнивает значение по типу поля (число, дата, булево, строка точно), в ссылочное поле вводит выбором с точным совпадением, при неоднозначности — ошибка со списком кандидатов.
- **BREAKING** Диалоги: действие видит открытый им диалог, `click(answer="Да")` отвечает в том же вызове, неожиданный диалог — ошибка сразу. `answer_dialog` возвращается при появлении диалога; без диалога за `timeout` — `ok: false`.
- `select_value` повторяет шаг при «does not support this action on this object», пока список не сформирован.
- `Client.reset()`; фикстура `testpilot` сбрасывает клиент перед каждым тестом.
- Ролевые клиенты: много профилей в одном файле, порт из пула машины (`port_range`) под общей блокировкой, несколько клиентов одновременно, повторный запуск профиля переиспользует клиент. Тест объявляет пользователя маркером или параметром фикстуры и переключается между живыми клиентами через `testpilot.as_user(...)`.
- Фикстура `testpilot_data`: учёт созданных объектов и их удаление после теста.
- Команда `1c-testpilot client start|stop --profile`, в том числе для ролевых профилей.
- MCP: один stdio-сервер на дерево со всеми профилями, профиль — параметр подключения.
- `Testpilot.epf` дорабатывается (тип значения поля, состояние объекта формы), входит в пакет и используется по умолчанию.
- Версия 1.9.2.post3.

## Capabilities

### New Capabilities

- `code-execution`: исполнение кода и запросов через обработку Testpilot без фильтра идентификаторов.
- `action-effects`: подтверждение эффекта `click` и `input_text`, ожидание и повтор.
- `dialog-answering`: обработка модальных диалогов внутри действий и `answer_dialog`.
- `value-selection`: устойчивость `select_value` к неготовому списку выбора.
- `pytest-isolation`: сброс клиента, пользователь теста, уборка созданных данных.
- `client-profiles`: много профилей, пул портов машины, несколько живых клиентов, переиспользование для MCP, CLI и pytest.
- `client-launch-cli`: запуск и остановка тест-клиента из командной строки без MCP.
- `helper-distribution`: поставка `Testpilot.epf` вместе с пакетом.

### Modified Capabilities

Нет: в `openspec/specs/` пока нет спецификаций.

## Impact

- Код:
  - `app/_code_execution.py`;
  - `app/_runtime.py` — click, input_text, answer_dialog, распознавание диалогов, launch_client;
  - `app/_value_selection.py`;
  - `app/_profiles.py` — поиск профиля по пользователю;
  - `app/_connections.py` — пул портов, блокировка машины, файл состояния;
  - `app/testpilot.py` — `Client.reset`;
  - `app/testpilot_pytest.py` — фикстуры, маркер;
  - `app/_cli.py`;
  - `pyproject.toml`.
- Обработка: `onec/Testpilot/src` — возможность `form_state` (состояние формы, объекта и значения полей), протокол прежний. Пересборка Конфигуратором на Windows.
- Тесты: `tests/test_code_filter.py` переписывается, добавляются unit-тесты на фейковом клиенте.
- Документация: `README.md`, `onec/Testpilot/README.md`, `docs/PYTHON_TESTING.md`, `docs/TOOLS.md`.
- Совместимость:
  - MCP-агенты получат `ok: false` там, где раньше был `ok: true` без эффекта;
  - защиту кода теперь дают только `TC1C_CODE_EXECUTION=false` и права пользователя 1С.

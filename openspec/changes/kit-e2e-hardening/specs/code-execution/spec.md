# Spec Delta

## Purpose

Исполнение произвольного кода BSL и запросов в сеансе тестируемого клиента через обработку Testpilot — для подготовки и проверки данных в тестах.

## ADDED Requirements

### Requirement: Код исполняется без фильтра идентификаторов
Система MUST передавать непустой код на исполнение без проверки идентификаторов по спискам запрещённых слов, включая `Выполнить`, `Execute`, `Вычислить`, `Eval`, `Записать`, `Удалить`. Переменные `TC1C_CODE_FORBIDDEN_WORDS` и `TC1C_CODE_ALLOWED_WORDS` MUST NOT влиять на исполнение.

#### Scenario: Запрос внутри кода
- **WHEN** тест вызывает `execute_code` на сервере с кодом `Результат = Новый Запрос("ВЫБРАТЬ 1 КАК Х").Выполнить().Выгрузить().Количество();`
- **THEN** код исполняется и возвращает `ok: true`, `result: 1`

#### Scenario: Запись объекта без настройки разрешённых слов
- **WHEN** `TC1C_CODE_ALLOWED_WORDS` не задана, а код вызывает `Объект.Записать()`
- **THEN** код исполняется без ошибки `forbidden_code`

#### Scenario: Старая переменная запрета игнорируется
- **WHEN** задано `TC1C_CODE_FORBIDDEN_WORDS=Сообщить`, а код вызывает `Сообщить("х")`
- **THEN** код исполняется без ошибки `forbidden_code`

### Requirement: Некорректный код отклоняется до отправки
Система MUST отклонять с `invalid_code`, ничего не отправляя в клиент, код, который не является непустой строкой или содержит незакрытый строковый литерал.

#### Scenario: Пустой код
- **WHEN** вызывается `execute_code` с `code="  "`
- **THEN** ответ `ok: false`, `code: invalid_code`, клиент не получает команд

#### Scenario: Незакрытая строка
- **WHEN** код содержит `Х = "abc;`
- **THEN** ответ `ok: false`, `code: invalid_code`

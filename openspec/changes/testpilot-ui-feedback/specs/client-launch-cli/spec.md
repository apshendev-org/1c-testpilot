## ADDED Requirements

### Requirement: Окно запущенного клиента развёрнуто
Клиент 1С, который testpilot запускает на Windows в рабочем сеансе, MUST открываться развёрнутым окном (флаг процесса `SW_MAXIMIZE`): сохранённый размер окна может быть шире экрана. Запуск на изолированном рабочем столе MUST NOT меняться.

#### Scenario: Сохранённый размер шире экрана
- **WHEN** testpilot запускает клиент пользователя, чьё окно сохранено шириной 1438 px, на экране 1024 px
- **THEN** окно клиента развёрнуто на экран

#### Scenario: Не Windows
- **WHEN** testpilot запускает клиент не на Windows
- **THEN** процесс запускается без флага окна

## MODIFIED Requirements

### Requirement: Исполнение при активной рабочей форме
Если активно не окно обработки Testpilot, исполнение кода, запроса и чтений формы MUST активировать окно обработки до записи запроса и MUST вернуть прежнее активное окно после ответа: сначала активацией его формы с handle, затем, если активным не стало прежнее окно, — активацией окна по ключу; результат возврата MUST проверяться чтением активного окна. Отказ возврата MUST NOT скрывать результат исполнения.

#### Scenario: Запрос после действий с формой
- **WHEN** тест записал документ в открытой форме и сразу вызывает `execute_query`
- **THEN** запрос выполняется без `reset()`, после ответа активна та же форма документа

#### Scenario: Форма выбора из ячейки
- **WHEN** форма выбора открыта из ячейки табличного документа, `find_rows` по её списку читает режим выделения через обработку
- **THEN** после чтения активна форма выбора, `find_rows` не отказывает `table_read_failed`

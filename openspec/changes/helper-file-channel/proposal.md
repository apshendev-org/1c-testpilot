## Why

Чтобы выполнить код (`execute_code`, `execute_query`, чтение режима выделения в `read_rows`/`find_rows`, состояние формы в наблюдении `click`), testpilot делает форму Helper активной, вводит запрос в её поле и нажимает «Выполнить», а потом возвращает прежнее окно. Для формы выбора, открытой из ячейки табличного документа, возврат не работает: Helper остаётся активным, testpilot видит `no_active_work_window`, `find_rows` отвечает `table_read_failed`, клавиатура уходит Helper (находка 1c_bgu20). Не помогли ни `ACTIVATE` по ключу окна и формы с handle, ни `Активизировать()` из кода Helper (записи `docs/spikes/testpilot-cell-edit/recording/03…07` кита).

Спайк spike:spk_414937a75f@v1 (`docs/spikes/testpilot-helper-idle` кита): обработчик ожидания в модуле формы Helper читает запрос из файла и пишет ответ файлом. Форма выбора из ячейки при этом остаётся активной, а код видит её элементы. Так же Vanessa выполняет код без формы (`VAExtension`, файлы событий и глобальный обработчик ожидания).

## What Changes

- Helper получает канал через файлы. При подключении testpilot передаёт ему каталог обмена (своё подключение — свой каталог). Обработчик ожидания Helper забирает `req-<id>.json`, выполняет запрос по тому же протоколу и пишет `res-<id>.json` атомарно. Форма Helper при этом не активизируется.
- testpilot пишет запрос в файл и ждёт ответ, если клиент запущен им локально, каталог доступен, а Helper подтвердил канал (`capabilities` содержит `file_channel`). Иначе — прежний путь через поля формы: клиент на другой машине, старый `Testpilot.epf`, канал не подключился.
- Форма Helper без служебного текста: в файловом режиме поля обмена скрыты, остаётся заголовок и строка состояния. В режиме полей Helper после нажатия забирает текст запроса и очищает поле; на форме — только последний ответ.
- Ограничение режима полей (форма выбора из ячейки теряет активность) записывается в спецификацию.

## Capabilities

### New Capabilities
- `helper-file-channel`: обмен запросами с Helper через файлы, без активизации его формы.

### Modified Capabilities
- `code-execution`: «Исполнение при активной рабочей форме» — активизация Helper только в режиме полей.

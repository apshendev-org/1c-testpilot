## MODIFIED Requirements

### Requirement: Исполнение при активной рабочей форме
В режиме полей, если активно не окно обработки Testpilot, исполнение кода, запроса и чтений формы MUST активировать окно обработки до записи запроса и MUST вернуть прежнее активное окно после ответа. Отказ возврата MUST NOT скрывать результат исполнения. Для формы выбора, открытой из ячейки табличного документа, возврат в режиме полей не работает: активным остаётся окно обработки. В файловом режиме окно обработки MUST NOT активизироваться.

#### Scenario: Запрос после действий с формой
- **WHEN** тест записал документ в открытой форме и сразу вызывает `execute_query`
- **THEN** запрос выполняется без `reset()`, после ответа активна та же форма документа

## ADDED Requirements

### Requirement: Код Helper без активизации его формы
Если клиент запущен этим testpilot локально и Helper подтвердил `file_channel`, исполнение кода, запроса и чтений формы MUST идти через файлы каталога обмена подключения и MUST NOT менять активное окно клиента.

#### Scenario: Форма выбора из ячейки
- **WHEN** форма выбора открыта из ячейки табличного документа, агент вызывает `find_rows` по её списку
- **THEN** поиск выполняется, после него активна форма выбора, `no_active_work_window` нет

### Requirement: Запрос выполняется один раз
Helper MUST удалить файл запроса до выполнения и MUST писать ответ атомарно (временный файл и переименование). testpilot MUST читать ответ только с `request_id` своего запроса.

#### Scenario: Ответ не дождались
- **WHEN** код не ответил до `timeout`, затем агент вызывает `execute_code` ещё раз
- **THEN** прежний код не выполняется повторно, его ответ приходит в `previous_result`

### Requirement: Канал не работает — отказ, а не поля
Если Helper не забрал запрос за пять интервалов опроса, вызов MUST вернуть `ok: false`, `code: "helper_channel_unavailable"` и MUST NOT повторять запрос через поля формы.

#### Scenario: Обработчик ожидания не сработал
- **WHEN** файл запроса лежит дольше пяти интервалов опроса
- **THEN** ответ `helper_channel_unavailable`, активное окно не менялось

### Requirement: Режим полей — запасной
Без `file_channel`, для клиента не на этой машине или без каталога обмена testpilot MUST исполнять через поля формы, как раньше. В этом режиме Helper MUST очищать поле запроса после нажатия.

#### Scenario: Старая обработка
- **WHEN** клиент запущен с `Testpilot.epf` без `file_channel`
- **THEN** код исполняется через поля, ответ как раньше

### Requirement: Форма Helper без служебного текста
В файловом режиме Helper MUST скрывать поля обмена и показывать только строку состояния.

#### Scenario: Пользователь смотрит на окно Helper
- **WHEN** канал через файлы подключён
- **THEN** на форме Helper нет текста запросов и ответов

## Why

Схемы инструментов MCP testpilot — главная статья расхода агентов проектов. В треде 1c_bgu20 «Макет АРМ КС» (thr_tipdp79usa, разбор thr_r9xkqmvftw#msg=4041) они заняли 19.5M из 80.7M входных токенов (24%). 16 вызовов ToolSearch подгрузили 33 схемы (47.9k токенов), и эти схемы уходили в каждом следующем запросе, компакция их не трогает. Сейчас сервер публикует 17 групп `tc_*` со 169 действиями: только 11 основных групп — 92k символов описаний, `tc_table` и `tc_field` — около 22k каждая. Кроме того:
- агент угадывает, в какой группе лежит действие (`tc_form(action="click")`, `tc_window(action="list")`): около 5 лишних вызовов за тред;
- 66 мелких шагов (`find` → действие → `get_active_window`) стоили 10.9M входа: каждый шаг заново отправляет контекст около 190k.

Спайк: не нужен — меняется только публикация действий в MCP. Обмен с клиентом 1С и сами действия прежние, тесты — на существующих записях `tests/recordings`.

## What Changes

- **BREAKING**: сервер MCP публикует два инструмента вместо групп `tc_*`:
  - `search` — каталог действий и их документация по запросу. Пустой запрос даёт группы с одной строкой и имена действий, запрос по имени — полную документацию действия.
  - `execute` — один вызов или пачка вызовов действий по имени (`[{"action": "find", "args": {…}}, …]`). Аргументы проверяются по сигнатуре действия до отправки в 1С. Пачка останавливается на первом отказе, ответ — по шагам. Ссылка `$N.поле` подставляет значение из ответа шага `N` этой пачки.
- Действия, их аргументы и ответы не меняются. Фильтры публикации прежние (версия платформы, настройки исполнения кода, скриншоты, журнал, видимость пользовательских функций): недоступного действия нет ни в `execute`, ни в `search`.
- Подсказки и ошибки testpilot, которые сейчас называют `tc_<группа>(action="…")`, называют действие по имени.
- Документация `docs/TOOLS.md` и README — по действиям, вызов через `execute`.
- Python API и pytest-плагин не меняются: они не ходят через MCP.

## Capabilities

### New Capabilities
- `mcp-tools`: какие инструменты публикует сервер MCP testpilot, поиск действий и пакетное исполнение.

### Modified Capabilities
- `client-profiles`: сценарий подключения по порту вызывает `connect` через `execute`, а не `tc_session`.

## Impact

- `app/_mcp.py` — публикация `search`/`execute` вместо регистрации групп; `app/_runtime.py`, `app/tc1c.py` — тексты подсказок и описаний с `tc_<группа>(action=…)` (около 30 мест); `app/server.py` — без изменений.
- Тесты `tests/` с вызовами через MCP-группы.
- `docs/TOOLS.md`, `README.md`, `onec/Testpilot/README.md`, `onec/Testpilot/CUSTOM_FUNCTIONS.md`.
- Кит (вне `testpilot/`): шаблон `AGENTS.template.md` (§3, §13) — в том же релизе; скиллы `testpilot-testing`, `report-verification`, `1c-run-diagnostics` — отдельным PR после релиза (скиллы доходят до проектов при слиянии в `master`, а testpilot — с релизом клона кита). Разрешение `mcp__1c-testpilot` не меняется.
- Пересечение: ветка `bb/bug/testpilot-helper-focus` (изменение `helper-request-form`) правит `_code_execution.py` и скилл `testpilot-testing`. Это изменение начинается после её слияния.

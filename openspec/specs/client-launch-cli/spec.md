# client-launch-cli Specification

## Purpose
Запуск и остановка тест-клиента 1С с обработкой Testpilot из командной строки, без MCP-сервера, чтобы внешние инструменты (dev_ib.py кита) готовили клиент для последующих pytest-прогонов.

## Requirements

### Requirement: Запуск клиента по профилю из командной строки
Команда `1c-testpilot client start --profile <имя>` MUST запустить клиент по профилю: `/TESTCLIENT -TPort`, `/Execute` с обработкой, подтверждение предупреждения безопасности, ожидание готовности. Затем MUST отключиться, оставить процесс работать и вывести JSON с `pid`, `host`, `port`, `version`, `execution_ready`. Стартовую форму БСП `ПредупреждениеБезопасности` подготовка MUST закрыть сама кнопкой «ЯОзнакомлен», иначе «НеЗапрещать»; кнопку запрета внешних обработок MUST NOT нажимать.

#### Scenario: Успешный запуск
- **WHEN** выполняется `1c-testpilot client start --profile ws_epf`
- **THEN** код выхода 0, в stdout JSON с `pid` и `port`, процесс 1С продолжает работать после выхода команды, pytest с этим профилем подключается к порту из `.testpilot-clients.json` и исполняет код

#### Scenario: Ролевой профиль
- **WHEN** выполняется `1c-testpilot client start --profile "роль:kfk_user"`, а клиент `роль:kfk_admin` уже работает
- **THEN** клиент kfk_user запущен на следующем свободном порту пула, клиент kfk_admin продолжает работать

#### Scenario: Профиль уже запущен
- **WHEN** `client start` вызывается для профиля, клиент которого работает
- **THEN** новый процесс не запускается, JSON содержит прежние `pid`, `port` и `reused: true`

#### Scenario: Неудачная подготовка
- **WHEN** клиент не стал готов за `wait` профиля или обработка не открылась
- **THEN** запущенный процесс завершён, код выхода ненулевой, в stderr JSON с `code` и `error`

#### Scenario: Предупреждение безопасности БСП при старте
- **WHEN** пользователю профиля при старте открыта форма БСП `ПредупреждениеБезопасности` на странице «После появления права» или «После обновления»
- **THEN** подготовка нажимает «ЯОзнакомлен» или «НеЗапрещать», внешние обработки остаются разрешены, `client start` завершается с `ok: true`

#### Scenario: Форма БСП не принимает ответ
- **WHEN** ни «ЯОзнакомлен», ни «НеЗапрещать» не нажимаются
- **THEN** отказ `helper_startup_blocked` с `dialog: "ПредупреждениеБезопасности"`, процесс завершён

### Requirement: Остановка клиента из командной строки
Команда `1c-testpilot client stop` MUST завершить клиент, запущенный `client start`, по `--pid` или по `--profile` (запись в `.testpilot-clients.json`), и вернуть код 0, если процесса уже нет.

#### Scenario: Остановка по pid
- **WHEN** выполняется `1c-testpilot client stop --pid <pid из start>`
- **THEN** процесс 1С завершён, код выхода 0

#### Scenario: Процесса нет
- **WHEN** процесс с указанным pid уже завершился
- **THEN** код выхода 0, в stdout `"stopped": false`

### Requirement: Стартовое окно, отказывающее в активации
Если при подготовке рабочее окно отказывает в активации с `target_not_interactive`, `invalid_element_state`, `client_busy` или `target_unavailable`, подготовка MUST пробовать остальные рабочие окна, затем повторять до срока `wait`, как при поиске обработки. Срок истёк — `helper_not_ready` с `last_error`.

#### Scenario: Новости у администратора
- **WHEN** `client start --profile ib`, при старте открыто окно «Новости», и его форма отказывает в активации
- **THEN** активируется главное окно, `client start` завершается с `ok: true`

### Requirement: Неудачный вход при старте — отказ сразу
Пока старт ждёт подключения и обработки, он MUST проверять процесс. Окно входа «Доступ к информационной базе» — MUST сразу отказ `login_failed` с `dialog` и завершение процесса; `error` MUST называть профиль, логин и причины: нет пользователя, пароль неверный или не передан, возможно — нет права входа. Процесс вышел — MUST сразу `client_exited` с кодом выхода. Иначе MUST ждать до `wait`. Окно проверяется на Windows, обычный рабочий стол.

#### Scenario: Пользователя нет в базе
- **WHEN** `client start --profile "роль:rmzds_admin"`, логина нет в базе, 1С открыла окно «Доступ к информационной базе»
- **THEN** через секунды после появления окна код выхода ненулевой, в stderr JSON с `code: "login_failed"`, `dialog: "Доступ к информационной базе"`, `client_stopped: true`; процесса 1С нет

#### Scenario: Неверный пароль
- **WHEN** логин есть, пароль профиля неверный, 1С открыла окно входа
- **THEN** отказ `login_failed`, как без пользователя; `error` называет профиль, логин и причины

#### Scenario: Процесс вышел во время подготовки
- **WHEN** процесс 1С завершился после подключения, пока обработка не готова
- **THEN** отказ `client_exited` с кодом выхода в `error`, без ожидания `wait`

#### Scenario: Долгий обычный старт
- **WHEN** 1С 90 с показывает «Загрузка конфигурационной информации...», затем главное окно, `wait` 600
- **THEN** запуск ждёт и завершается `ok: true, execution_ready: true`

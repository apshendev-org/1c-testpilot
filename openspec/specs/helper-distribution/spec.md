# helper-distribution Specification

## Purpose
Обработка `Testpilot.epf` поставляется вместе с Python-пакетом, чтобы её не нужно было брать из клона репозитория.

## Requirements

### Requirement: Обработка входит в пакет
Установленный пакет MUST содержать `Testpilot.epf` той же версии, что и исходники в `onec/Testpilot`. Если `code_epf` и `TC1C_CODE_EPF` не заданы, а обработка нужна, система MUST использовать файл из пакета.

#### Scenario: Запуск без указания пути
- **WHEN** профиль с `base` не задаёт `code_epf`, `TC1C_CODE_EPF` пуст, а код включён
- **THEN** клиент запускается с `/Execute` на файл из установленного пакета

#### Scenario: Явный отказ от обработки
- **WHEN** задан `code_epf=""`
- **THEN** клиент запускается без обработки, как и раньше
